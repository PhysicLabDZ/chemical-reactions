# محاكاة التفاعلات الكيميائية

محاكاة تفاعلية لتفاعلات المعادن مع المحاليل الشاردية، موجهة لتلاميذ السنة الرابعة متوسط وفق المنهاج الجزائري (الجيل الثاني).

## ماذا تعرض؟
- تفاعل المعادن مع المحاليل الشاردية.
- عدسة مكبرة تُظهر تبادل الإلكترونات على المستوى المجهري.
- المعادلات الشاردية والجزيئية.

## الاستعمال
افتح الرابط من الهاتف أو الحاسوب: https://physiclabdz.github.io/chemical-reactions/
ويمكن تثبيتها كتطبيق من قائمة المتصفح (Install app).

# محاكاة التفاعلات الكيميائية

محاكاة تفاعلية لبعض التفاعلات الكيميائية في المحاليل الشاردية، موجهة لتلاميذ السنة الرابعة متوسط.

## التفاعلات المتاحة
- **حمض + معدن**: حمض الكلور (HCl) أو حمض الكبريت (H₂SO₄) مع الزنك أو الحديد أو المغنيزيوم.
- **محلول ملحي + معدن**: كبريتات النحاس (CuSO₄) أو نترات الفضة (AgNO₃) مع الحديد أو النحاس.
- **حمض + كربونات**: حمض الكلور مع كربونات الكالسيوم.

يقتصر الاختيار على التركيبات التي يحدث فيها تفاعل فعلًا.

## ماذا تعرض؟
- حركة الشوارد في المحلول وتشكّل الغاز أو الراسب.
- عدسة مكبرة (بالنقر على حافة الصفحة) تُظهر تبادل الإلكترونات على سطح المعدن.
- العمليات الجارية (فقدان الإلكترونات واكتسابها).
- المعادلة الشاردية والمعادلة الإحصائية (الجزيئية) لكل تفاعل.
- التحكم بالبدء والإيقاف والتعيين، وبسرعة التفاعل.
